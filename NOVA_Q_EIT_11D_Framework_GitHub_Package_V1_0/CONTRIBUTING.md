# Contributing

This repository is safety-bounded by Article 7.

Allowed contributions:
- conceptual documentation improvements
- safe visual appendix additions
- citation corrections
- code organization and validation scripts
- non-clinical research-mapping improvements

Not allowed:
- diagnosis claims
- treatment recommendations
- cure claims
- clinical prediction systems
- MRI reinterpretation workflows
- biological intervention protocols
- human-use guidance
