# Security and Safety Policy

## Article 7 Safety Boundary

This repository is conceptual research only.

Do not use this project for diagnosis, treatment, cure claims, clinical prediction,
MRI reinterpretation, biological intervention protocols, human-use guidance, or
replacement of medical professionals.

## Reporting Safety Issues

If wording or code appears to cross Article 7 boundaries, open an issue labeled:

`article-7-safety`

The model must return to D10 and stop.
